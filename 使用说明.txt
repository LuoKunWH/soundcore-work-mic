录音豆麦克风（托盘程序）

运行环境（使用前请先具备）
- Windows 10/11 64 位电脑，已打开蓝牙（已在 Windows 11 64 位上验证）
- Python 3.12 64 位
- 已用 scripts\install.ps1 装好本程序依赖
- 已安装官方 VB-CABLE（VBCABLE_Driver_Pack46），并已重启
- soundcore Work 录音豆（型号 D3200）

第一次怎么装
1. 安装 Python 3.12 64 位：https://www.python.org/downloads/windows/
   安装时勾选 Add python.exe to PATH。不要用 32 位，也不要改用 3.13。
2. 在本目录打开 PowerShell，执行：
   powershell -ExecutionPolicy Bypass -File .\scripts\install.ps1
3. 安装官方 VB-CABLE（本程序不附带安装包）：
   打开 https://vb-audio.com/Cable/ 下载 VBCABLE_Driver_Pack46.zip
   解压全部文件，以管理员身份运行安装程序，安装后重启电脑。
   重启后到「系统 > 声音」看一下默认播放设备：如果变成了 CABLE Input，请改回电脑扬声器。
   麦克风不用手动改，开始传声时会自动切到录音豆，停止后自动切回。

日常怎么用
1. 先断开手机上的飞书、soundcore 或其他占用录音豆的连接，把豆放在电脑附近。
2. 双击桌面上的「录音豆麦克风」，右下角托盘会出现图标。
3. 左键或右键点一下图标，在弹出的面板里点「开始桥接」。再点一次图标、点面板外面，或按 Esc，面板就收起。
   面板上有当前状态、三步进度（连接 → 按录音键 → 传声）、下一步提示和主按钮。正在传声时会显示已用时间。
   图标是录音豆外形，图案表示状态：
   - 灰色横线：未连接
   - 橙色三个点：正在连接
   - 蓝色圆点：已经连上，请按一下豆上的录音键
   - 绿色声波：正在传声，对着豆说话
   中途在豆上按暂停，图标会回到蓝色，连接还在；再按一下录音键就接着传声。
4. 图标变绿时，系统默认麦克风会自动切到 CABLE Output；停止桥接或退出程序时自动切回原来的麦克风。
   在豆上按暂停不会切回。也可以在面板的「麦克风」一栏手动点「录音豆」或「系统麦克风」。
   如果某个软件在自己的设置里固定选了麦克风，需要在软件里选成 CABLE Output。
   面板底部是「整理录音 · 声音设置 · 退出」。声音设置只打开 Windows 的声音设置。
5. 用完后点「停止桥接」，再按一下豆上的键，把豆上的录音也停掉。点「退出」可关闭托盘程序。

豆里的录音
- 豆当麦克风时自己也会录一份文件，连上手机后会传到飞书。
- 「停后删录音」（默认开）：桥接期间传过声的录音，在你按豆上的键结束后自动从豆里删掉。
  没删成的会记下来，下次开始桥接时再删。只删当麦克风传过声的录音。
- 「整理录音」：列出豆里所有录音（开始时间、时长，当麦克风录的标「麦克风」）。
  可以勾选后删除、一次选中麦克风录的，或一键清理全部。删除前都会确认。正在录的那条不能删。
  要在没有桥接时使用。
- 删除不能恢复，飞书也就收不到了。第一次建议先删一条无关紧要的试试。

请注意
- 面板右上角的小字是版本号和提交编号，每次更新都会不同。更新后要先在面板里点「退出」，再重新启动，新版本才会生效。
- 这个程序不会修改系统默认扬声器。默认麦克风只在开始传声、停止桥接和你点面板开关时切换。
- 电脑不会把声音存成文件，也不会转写。
- 程序不会替你按下录音键，也不会远程停掉豆上的录音。
- 程序不会升级固件或解绑设备。豆里的录音只删当麦克风传过声的，和你在「整理录音」里确认要删的。
- 如果豆已经在录音，却一直停在蓝色，请先按一下停掉，再按一次开始。
