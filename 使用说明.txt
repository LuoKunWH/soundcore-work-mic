录音豆麦克风（托盘程序）

运行环境（使用前请先具备）
- Windows 10/11 64 位电脑，已打开蓝牙（已在 Windows 11 64 位上验证）
- Python 3.12 64 位
- 已用 scripts\install.ps1 装好本程序依赖
- 已安装官方 VB-CABLE（VBCABLE_Driver_Pack46），并已重启
- soundcore Work 录音豆（型号 D3200）

第一次怎么装
1. 安装 Python 3.12 64 位：https://www.python.org/downloads/windows/
   安装时勾选 Add python.exe to PATH。不要用 32 位，也不要改用 3.13。
2. 在本目录打开 PowerShell，执行：
   powershell -ExecutionPolicy Bypass -File .\scripts\install.ps1
3. 安装官方 VB-CABLE（本程序不附带安装包）：
   打开 https://vb-audio.com/Cable/ 下载 VBCABLE_Driver_Pack46.zip
   解压全部文件，以管理员身份运行安装程序，安装后重启电脑。
   重启后到「系统 > 声音」看一下默认播放设备：如果变成了 CABLE Input，请改回电脑扬声器。
   麦克风可以自己选成 CABLE Output，程序不会替你改默认设备。

日常怎么用
1. 先断开手机上的飞书、soundcore 或其他占用录音豆的连接，把豆放在电脑附近。
2. 双击桌面上的「录音豆麦克风」，右下角托盘会出现图标。
3. 右键图标，点「开始桥接」。
   - 橙色：正在连接
   - 蓝色：已经连上，请按一下豆上的录音键
   - 绿色：正在录音，对着豆说话
4. 在要用的软件里，把麦克风选成 CABLE Output。
5. 用完后点「停止桥接」，再按一下豆上的键，把豆上的录音也停掉。点「退出」可关闭托盘程序。

请注意
- 这个程序不会修改系统默认扬声器或默认麦克风。
- 电脑不会把声音存成文件，也不会转写。
- 程序不会替你按下录音键，也不会远程停掉豆上的录音。
- 程序不会升级固件、解绑设备，或删除豆里已有的录音。
- 如果豆已经在录音，却一直停在蓝色，请先按一下停掉，再按一次开始。
